# 🧮 Calculator App

A simple and responsive calculator web application built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations with a clean and user-friendly interface.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🧹 Clear (C) functionality
- ⚡ Real-time result display
- 🎨 Simple and responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript 

---
## 🎯 Purpose of the Project

This project was built to strengthen my understanding of:

- DOM manipulation
- Event handling in JavaScript
- Handling user input
- Frontend logic building
- Basic UI design
  

## 🔐 Security Note

The project currently uses `eval()` for evaluating expressions (for learning purposes).  
In production applications, `eval()` is not recommended due to security risks such as code injection.  
A safer approach would involve implementing a custom expression parser.
